# Yassmine Ben Mahmoud — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure, SEO metadata and Person structured data
- `style.css` — all layout, responsive styling and visual design
- `script.js` — mobile navigation, scroll reveal and reading progress
- `assets/images/` — add your images here

## Run locally
Open `index.html` in a browser. For local development, you can also use VS Code Live Server.

## Personalise before publishing
1. Replace the portrait placeholder with your portrait.
2. Replace the four project placeholders with your project images and links.
3. Update the LinkedIn URL to your actual profile.
4. Replace `https://your-domain.com/` in the canonical tag with your real domain.
5. Add a real `assets/images/og-cover.jpg` social sharing image.
6. Confirm the contact details and dates.
7. Add a `robots.txt` and `sitemap.xml` after choosing your final domain.

## Project image options
You can replace each `.project-image` anchor's contents with:
`<img src="assets/images/project-01.jpg" alt="Short descriptive project image text">`
Then add `width:100%; height:100%; object-fit:cover;` to the image style in `style.css`.

## SEO note
The page includes a unique title, meta description, canonical placeholder, Open Graph metadata, semantic sections, descriptive headings and Person JSON-LD. SEO readiness also depends on the final domain, image alt text, performance, Search Console indexing and real project content.
